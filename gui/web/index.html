Tutorial · Iniciar sesión

Se hace una sola vez. Nunca se te pide tu usuario ni tu contraseña de Spotify.

1

Crea tu app de Spotify

Hecho

Spotify exige que cada persona cree su propia «app» gratuita. Es lo que permite leer tus playlists.

  1. Abre el panel de Spotify e inicia sesión.
  2. Pulsa Create app. Nombre y descripción: lo que quieras (por ejemplo «Burdamix»).
  3. En Redirect URI copia exactamente esto y pulsa Add:
  4. En «Which API/SDKs are you planning to use?» marca Web API.
  5. Acepta los términos y pulsa Save.
  6. Abre tu app nueva → Settings. Verás el Client ID y, con «View client secret», el Client secret. Pégalos aquí:
2

Inicia sesión en Spotify

Hecho

Hace falta solo para tus playlists y tus favoritos. Para canciones sueltas y álbumes no es necesario. Se abrirá tu navegador: elige tu cuenta y pulsa Aceptar. Tienes 3 minutos.

5

Nombre de los archivos

Cómo se llaman las canciones que bajas. El artista siempre va dentro de las etiquetas, así que el reproductor lo muestra igual aunque el nombre solo tenga el título.

Saltar introducciones e interludios

Las pistas cortas (menos de 50 s, o intro/outro de menos de 95 s) no se descargan.

Usar mi sesión de YouTube

Solo si YouTube pide iniciar sesión (videos para mayores de edad). Lee la sesión que ya tienes abierta en ese navegador; no se guarda ni se envía a ningún sitio. Ciérralo antes de bajar.

Actualizar yt-dlp

YouTube cambia cada pocas semanas. Si una descarga falla de repente, actualiza esto.
